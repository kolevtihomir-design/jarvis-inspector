JARVIS Inspector

Правилната версия е Chrome разширението с един мигащ бутон върху всяка страница.

Как да го инсталираш:
  1. Отвори chrome://extensions
  2. Включи Developer mode
  3. Натисни Load unpacked
  4. Избери папката jarvis-inspector-extension

След това на Facebook, Instagram, новини и всеки сайт ще виждаш мигащия бутон. Натискаш го → получаваш вердикт.
