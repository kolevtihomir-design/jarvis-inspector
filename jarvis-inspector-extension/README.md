# JARVIS Inspector — Chrome Extension

## Инсталация (1 минута)

1. Отвори Chrome → адресна лента → `chrome://extensions`
2. Горе вдясно → **Режим за разработчици** (Developer mode) → ВКЛ
3. Бутон **"Зареди разпакетирано"** (Load unpacked)
4. Избери папката: `C:\Users\BOSS\Desktop\JarvisAleks\jarvis-inspector-extension`
5. Готово — зеленият бутон се появява на всяка страница

## Използване

- **Зеленият светещ бутон** долу вдясно → видим на всяка страница
- **Кликни** → Jarvis анализира страницата и показва:
  - ✅ РЕАЛНО / ❌ ФЕЙК / ⚠️ ПОДОЗРИТЕЛНО
  - Процент увереност
  - Обяснение на български
  - Конкретни проблеми (ако има)
- **Кликни отново** → затваря панела
- Jarvis трябва да работи на `localhost:3001`
